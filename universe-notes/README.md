# universe-notes

The note-taker from Section 1, trimmed to its data. `notes/keynote-highlights.json`
holds sample notes from the GitHub Universe '26 keynote.

Run `npm run list` to print the keynote highlight titles grouped by topic. That
makes it a good first issue for the `issue-to-pr` skill in
[Section 2](../02-github-copilot-latest-features/).
